ELog

Warehouse-to-store delivery management

Plan, load, dispatch and track electronics delivery in one workflow.

ELog is a lightweight product UI prototype for SME electronics distributors. The interface focuses on Excel order import, fixed-route planning, vehicle capacity validation, LIFO loading, GPS tracking and driver e-POD.

UI Handoff for Coding / Figma Design

This prototype is structured as product screens instead of use-case buttons. Each screen can become a page/component in React, Vue, Angular, or a Figma frame.

Desktop Pages

Dashboard, Orders Import, Route Planning, Vehicle Allocation, Warehouse Loading, Dispatch Center, Trip Monitoring, Master Data, Users, Reports.

Mobile Pages

Driver Trip Detail, Stop Checklist, Navigation action, e-POD submission, Exception report.

Core Components

Sidebar, topbar, metric card, data table, status pill, stepper, route chips, map panel, drawer, modal, phone frame.
